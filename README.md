## 🔧 Customization & Usage

To customize this portfolio:

1. **Update Personal Info**: Edit `index.html` with your details
2. **Modify Styling**: Customize colors and fonts in `styles/style.css`
3. **Add Interactivity**: Enhance `scripts/main.js` with additional features
4. **Replace Images**: Update profile picture in `images/` folder
5. **Deploy**: Push to GitHub Pages or any static hosting service

### Deploy to GitHub Pages
```bash
git push origin main
# Enable GitHub Pages in repository settings (Source: main branch)
```
